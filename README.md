## Project Features

- Create, edit, complete, and delete tasks
- Search, filter, and sort tasks
- Task priorities, categories, and due dates
- Dashboard summary cards
- Light and dark themes
- Responsive interface
- Flask backend and SQLite persistence
- Server-side validation and CSRF protection

## Technology Stack

- Python and Flask
- SQLite
- HTML5 and CSS3
- Vanilla JavaScript
- Python unittest
